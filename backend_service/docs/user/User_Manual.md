# 访客管理系统用户手册

## 概述

访客管理系统是一个现代化的数字化访客管理解决方案，帮助企业和机构高效管理访客流程，从访客预约、审批、签到到签出的全生命周期管理。

### 系统特性

- **数字化流程**: 无纸化访客登记和管理
- **实时通知**: 自动通知相关人员访客状态变化
- **安全管控**: 多层次的安全验证和权限控制
- **数据分析**: 详细的访客统计和报表分析
- **移动支持**: 支持手机端操作和二维码扫描

## 功能模块详解

### 1. 仪表板

仪表板提供系统的整体概览，包括：

#### 关键指标
- **今日访客数**: 当天的访客总数
- **待审批数**: 需要处理的审批请求
- **已签到数**: 当前在场的访客数量
- **本月访客数**: 本月累计访客数

#### 图表分析
- **访客趋势图**: 显示最近30天的访客数量变化
- **部门访客分布**: 各部门接待访客的比例
- **访客状态分布**: 不同状态访客的占比

![仪表板](../images/dashboard.png)

### 2. 访客管理

#### 2.1 访客列表

访客列表显示所有访客记录，支持多种筛选和搜索功能。

**功能特性**:
- 按姓名、电话、公司搜索
- 按状态筛选（待审批、已审批、已签到等）
- 按时间范围筛选
- 导出访客数据

**操作步骤**:
1. 点击左侧菜单"访客管理" → "访客列表"
2. 使用搜索框或筛选器查找特定访客
3. 点击访客记录查看详细信息

![访客列表](../images/visitor-list.png)

#### 2.2 新增访客

**操作步骤**:
1. 在访客列表页面点击"新增访客"按钮
2. 填写访客基本信息：
   - **姓名**: 访客真实姓名
   - **联系电话**: 有效的手机号码
   - **邮箱**: 用于接收通知（可选）
   - **身份证号**: 用于身份验证（可选）
   - **公司名称**: 访客所属公司
3. 填写访问信息：
   - **来访目的**: 选择或输入来访原因
   - **接待员工**: 选择负责接待的员工
   - **访问日期**: 计划访问的日期
   - **访问时间**: 预计到达和离开时间
4. 上传访客照片（可选）
5. 点击"提交"完成创建

![新增访客](../images/add-visitor.png)

#### 2.3 访客审批

**审批流程**:
1. 访客信息提交后，系统自动通知相关审批人
2. 审批人登录系统查看待审批列表
3. 点击访客记录进入审批页面
4. 审核访客信息，选择"通过"或"拒绝"
5. 填写审批意见（可选）
6. 提交审批结果

**审批权限**:
- 部门经理：可审批本部门访客
- 安全管理员：可审批所有访客
- 系统管理员：拥有最高审批权限

![访客审批](../images/visitor-approval.png)

#### 2.4 访客签到/签出

**签到流程**:
1. 访客到达后，在前台或自助终端扫描二维码
2. 系统验证访客身份和审批状态
3. 拍照确认（可选）
4. 打印访客卡或发送电子通行证
5. 记录签到时间和地点

**签出流程**:
1. 访客离开时扫描二维码或刷访客卡
2. 系统记录签出时间
3. 自动计算访问时长
4. 发送访问总结通知

![签到界面](../images/checkin.png)

### 3. 员工管理

## 常见问题解答

### Q1: 忘记密码怎么办？
**A**: 在登录页面点击"忘记密码"，输入邮箱地址，系统会发送重置密码的链接到您的邮箱。

### Q2: 如何修改个人信息？
**A**: 登录后点击右上角头像，选择"个人设置"，在个人信息页面进行修改。

### Q3: 访客审批权限如何设置？
**A**: 系统管理员可以在"用户管理"中为用户分配不同的角色，不同角色拥有不同的审批权限。

### Q4: 如何导出访客数据？
**A**: 在访客列表页面，使用筛选条件选择需要导出的数据，然后点击"导出"按钮，选择导出格式。

### Q5: 访客二维码多长时间有效？
**A**: 默认情况下，访客二维码在访问日期当天有效。管理员可以在系统设置中调整有效期。

### Q6: 如何设置访客照片拍摄？
**A**: 在系统设置的"访客设置"中，可以配置是否强制要求访客拍照，以及照片的质量要求。

### Q7: 支持哪些浏览器？
**A**: 系统支持Chrome、Firefox、Safari、Edge等主流浏览器的最新版本。建议使用Chrome浏览器以获得最佳体验。

### Q8: 如何处理访客信息变更？
**A**: 如果访客信息需要修改，可以在访客详情页面点击"编辑"按钮进行修改。重要信息修改可能需要重新审批。

### Q9: 系统支持多语言吗？
**A**: 目前系统支持中文和英文，可以在个人设置中切换语言。

### Q10: 如何联系技术支持？
**A**: 如遇到技术问题，可以通过以下方式联系支持团队：
- 邮箱：support@visitor.com
- 电话：400-123-4567
- 在线客服：系统右下角的客服按钮

## 最佳实践建议

### 1. 访客管理最佳实践

- **提前预约**: 建议访客提前1-2天进行预约，确保有足够时间进行审批
- **信息准确**: 确保访客信息准确完整，避免因信息错误导致的审批延误
- **及时审批**: 审批人应及时处理审批请求，避免影响访客行程
- **规范流程**: 建立标准的访客接待流程，确保安全和效率

### 2. 安全管理建议

- **定期审查**: 定期审查访客权限和审批流程，确保安全性
- **培训员工**: 对相关员工进行系统使用培训，提高操作效率
- **备份数据**: 定期备份访客数据，防止数据丢失
- **监控异常**: 关注异常访客行为，及时处理安全风险

### 3. 系统维护建议

- **定期更新**: 及时更新系统版本，获得最新功能和安全补丁
- **性能监控**: 监控系统性能，确保稳定运行
- **用户反馈**: 收集用户反馈，持续改进系统功能
- **文档更新**: 及时更新操作文档，确保信息准确性
