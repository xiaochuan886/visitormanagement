## 📋 文档信息
- **版本**: v3.0.0
- **创建日期**: 2025-06-17
- **最后更新**: 2025-06-20
- **适用角色**: 架构师、技术经理、高级开发者

## 🎯 系统概述

访客管理系统后端是一个基于 **FastAPI** 的企业级Web服务，采用 **Clean Architecture + DDD（领域驱动设计）** 架构模式，支持**多租户**、**高性能**、**可扩展**的访客管理业务。

### 核心特性
- ✅ **多租户架构**: 完全的数据隔离和安全性
- ✅ **Clean Architecture**: 清晰的分层架构，易于维护和测试
- ✅ **场景化配置引擎**: 四大核心场景模板 + 智能路由系统
- ✅ **全流程覆盖**: 从访客申请到离园的完整业务闭环
- ✅ **门岗前台系统**: 门岗验证、前台签到、移动端同步
- ✅ **高性能**: 156个API端点，响应时间 < 200ms，支持1000+并发
- ✅ **企业级功能**: 审计追踪、软删除、权限控制、设备管理
- ✅ **现代技术栈**: Python 3.12, FastAPI, PostgreSQL, Redis

### 技术架构模式

#### 1. Clean Architecture 分层
```
app/
├── api/              # API接口层 (156个端点)
├── application/      # 应用业务层 (10个服务)
├── domain/          # 领域模型层 (20个模型)
├── infrastructure/  # 基础设施层
└── core/           # 核心配置层
```

#### 2. DDD 领域模型
- **聚合根**: Visitor, Employee, Site, Department, ScenarioTemplate, GateDevice
- **实体**: 具有唯一标识的业务对象
- **值对象**: 不变的业务概念  
- **领域事件**: 业务状态变化的通知
- **场景上下文**: 场景执行的边界上下文

## 🎯 场景化配置引擎

### 四大核心场景

#### 1. 访客自主申请场景
- **触发条件**: 访客主动发起申请
- **配置要素**: 表单配置 + 审批工作流 + 权限规则
- **自动路由**: 根据访问目的自动选择审批路径

#### 2. 员工邀约已知访客场景
- **触发条件**: 员工预先知道访客信息
- **配置要素**: 简化表单 + 快速审批 + 预设权限
- **智能优化**: 重复访客自动识别和快速通道

#### 3. 员工邀约未知访客场景
- **触发条件**: 员工创建开放性邀请
- **配置要素**: 邀请链接 + 批量审批 + 权限模板
- **灵活配置**: 支持活动邀请和群体访问

#### 4. 员工批量邀约场景
- **触发条件**: 大规模访客活动
- **配置要素**: Excel导入 + 批量处理 + 统一配置
- **高效处理**: 批量操作和并行处理

### 智能路由引擎
```python
class ScenarioRouter:
    """场景智能路由器"""
```
