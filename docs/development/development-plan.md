## 🏗️ 系统架构概览

### 技术栈选型
```yaml
前端生态:
  - Web管理端: React 18 + TypeScript + Ant Design + Zustand
  - 门岗设备端: React 18 + TypeScript + PWA + 硬件集成
  - 前台系统: React 18 + TypeScript + Ant Design + 实时通信
  - 设备端自助: React 18 + TypeScript + PWA + 硬件API
  - 移动端备用: React Native + TypeScript (iOS/Android)
  - 小程序备用: React + TypeScript (微信小程序)
  - 访客H5: React 18 + TypeScript + 移动优化

后端架构:
  - API服务: FastAPI + Python 3.11 + Clean Architecture
  - 数据库: PostgreSQL 15 + Redis 7
  - 消息队列: Redis Stream + Celery
  - 文件存储: MinIO / AWS S3
  - 监控: Prometheus + Grafana
  - 日志: ELK Stack

DevOps:
  - 容器化: Docker + Docker Compose
  - CI/CD: GitHub Actions / GitLab CI
  - 部署: Kubernetes / Docker Swarm
  - 监控: APM + 健康检查
```
